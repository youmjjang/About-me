HTTP Status Pattern Analyzer

웹 서버 로그에서 HTTP 상태코드 유형별 시간 구간 및 경고 임계값 설정에 따른 이상 패턴 탐지 성능 비교

이 앱은 웹 로그를 검토하는 사람이 논문의 유형별 시간·횟수 기준으로 먼저 확인할 IP와 이유를 찾도록 돕습니다.

오류가 난 시간을 찾는 앱이 아니라, 반복 오류 패턴을 기준으로 먼저 검토할 곳을 좁혀주는 도구입니다. 논문의 모의실험에서 유형별 F1이 가장 높았던 기준을 기본 분석 규칙으로 실제 계산에 사용합니다.

해석

반복 횟수가 기준을 넘은 Host/IP부터 우선 확인하도록 보여줍니다. 401/403은 인증·권한, 404는 경로 탐색, 429는 과도한 요청, 5xx는 서버 오류의 집중 발생을 의미합니다.
